# Changelog

All notable changes to this project are documented here. The format
follows Keep a Changelog and the project is not yet published; version
stays 0.1.0 until the first npm release.

## 0.1.0 (unreleased)

### Added

- Forty public tasks generated by `scripts/gen-tasks.mjs` (seed
  20261015), plus a hidden-split mode (`--split hidden`, `a11yh-` ids)
  that stays out of git and npm.
- `easy` and `hard` tiers. Hard tasks use a separate page skeleton -
  grouped fields named by `aria-labelledby` chains, a `role="tablist"`
  widget, a table with spanning headers - so a template-aware regex
  fixer scores 1.000 on easy and about 0.36 on hard in the E2E gate.
- `--tasks <path>` on the CLI, `tasksPath` on the SDK, `?tasks=` and
  `tasksPath` on the HTTP API (allow-listed by `A11Y_TASK_DIRS`), and
  `A11Y_TASKS` for the MCP server.
- Per-tier report breakdown: `run` and `score` print a `## By tier`
  table (solved n/N, mean, defects fixed, regressions, content lost),
  and JSON reports carry `rows[].details` and a `tiers` summary on the
  CLI, SDK, API, and MCP surfaces.

### Changed

- `unlabeled-input` and `empty-link` resolve `aria-labelledby` id chains
  in accName order: a present `aria-labelledby` wins over `aria-label`,
  `label`, and link text, so a dangling or empty reference fails.
- `tabindex-positive` also fails a key handler that cancels keys
  unconditionally or on Tab (a focus trap, WCAG 2.1.2).
- `div-button` also fails a control nested inside `a[href]`/`button` or
  inside an `aria-hidden="true"` subtree.
- `no-focus-style` requires the focus rule's base selector to match a
  rendered focusable element and the indicator to be visible (not
  `none`, `0`, `transparent`, or the backdrop color).
- `stylesDeleted` reads parsed markup, so a `<style>` tag inside an HTML
  comment or `style=` in prose no longer counts as styling.

### Fixed

- The hard-tier `div-button` breaker read `h.cardHref`/`h.cardText`
  instead of `h.hooks.*`, writing `href="undefined"` into 9 of 13 public
  hard prompts. The generator now throws when `undefined`, `NaN`,
  `[object Object]` or `null` appears in any generated prompt or page,
  and the E2E scans shipped and hidden data for the same tokens.
- The inline note span is drawn against the body background it sits on;
  a stray draw could land under 4.5:1 and make a reference page fail its
  own grader. The generator grades every reference page with the built
  package and re-draws until it scores exactly 1 (the E2E holds this
  over 25 hidden seeds).
